2. TARGET DEFINITIONS & OPERATIONAL MANDATES
--------------------------------------------------------------------------------
1. Target: schedule_delay_3m
   - Definition: Binary indicator whether project milestone completion date is delayed / rescheduled within the next 3 months.
   - OOT Class Prevalence: 58.81% (2,227 positive / 3,787 labelled OOT rows).
   - Champion Model: CalibratedClassifierCV(RandomForestClassifier, method='sigmoid').
   - Calibrated: YES (Fitted strictly on validation split Dec 2025–Jan 2026).
   - Production OOT Performance: ROC-AUC = 0.9723, PR-AUC = 0.9722, Brier = 0.0391.

2. Target: cost_overrun_state_3m
   - Definition: Binary indicator whether cumulative expenditure exceeds sanctioned original cost (cost overrun state) in 3 months.
   - OOT Class Prevalence: 31.88% (1,208 positive / 3,789 labelled OOT rows).
   - Champion Model: Balanced RandomForestClassifier (200 trees, max_depth=12, class_weight='balanced').
   - Calibrated: Inherently calibrated via balanced tree bagging.
   - Production OOT Performance: ROC-AUC = 0.9895, PR-AUC = 0.9881, Brier = 0.0386.

3. Target: schedule_revision_3m
   - Definition: Binary indicator whether project authorities formally revise completion date within the next 3 months.
   - OOT Class Prevalence: 1.19% (45 positive / 3,787 labelled OOT rows).
   - Champion Model: L2-Regularized Logistic Regression (C=1.0).
   - Calibrated: Sigmoid logistic odds.
   - Production OOT Performance: ROC-AUC = 0.8264, PR-AUC = 0.0519, Brier = 0.0176.
