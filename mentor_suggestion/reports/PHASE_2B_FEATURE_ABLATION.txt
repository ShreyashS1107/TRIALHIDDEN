--------------------------------------------------------------------------------
1. ABLATION METHODOLOGY & SUBSET DEFINITIONS
--------------------------------------------------------------------------------
To precisely determine WHERE any incremental predictive value comes from—or why
degradation occurs—we executed controlled ablations across six distinct feature
configurations for each of the three active prediction targets:

- Configuration A (Champion Baseline):
  * Features: 75 PAIMANA Production Features (71 numerical + 4 categorical).
  * Archetype Benchmarks: 0.

- Configuration B (Full Valid Benchmark Model):
  * Features: 75 PAIMANA Features + 6 Valid Benchmark Features (81 total).
  * Valid Benchmarks: `cluster_hist_delay_rate_smoothed_t`, `cluster_hist_median_delay_months_t`,
    `cluster_hist_cost_revision_rate_t`, `cluster_distance_to_centroid_t`,
    `cluster_slippage_deviation_t`, `is_legacy_linked`.

- Configuration C (PAIMANA + Benchmark Outcome Statistics Only):
  * Features: 75 PAIMANA Features + 3 Historical Outcome Rates (78 total).
  * Features: `cluster_hist_delay_rate_smoothed_t`, `cluster_hist_median_delay_months_t`,
    `cluster_hist_cost_revision_rate_t`.

- Configuration D (PAIMANA + Benchmark Deviation Features Only):
  * Features: 75 PAIMANA Features + 2 Point-in-Time Deviations (77 total).
  * Features: `cluster_slippage_deviation_t`, `cluster_distance_to_centroid_t`.

- Configuration E (PAIMANA + Distance & Continuity Indicators Only):
  * Features: 75 PAIMANA Features + 2 Geometric/Linkage Features (77 total).
  * Features: `cluster_distance_to_centroid_t`, `is_legacy_linked`.

- Configuration F (Research Diagnostic Only: PAIMANA + One-Hot Cluster ID):
  * Features: 75 PAIMANA Features + 1 Categorical `cluster_id` (76 total).
  * Purpose: Determine if opaque cluster membership carries predictive information
    independent of continuous benchmark statistics.

Key Takeaway for Schedule Delay:
- Adding ANY archetype benchmark group degrades OOT PR-AUC and ROC-AUC relative to
  the PAIMANA baseline.
- Outcome statistics (Config C), deviations (Config D), and Cluster ID (Config F)
  all suffer small negative deltas (-0.0008 to -0.0012).
- Root Cause: PAIMANA's direct physical progress trajectory (`months_to_original_doc_t`,
  `current_schedule_status`, `physical_progress_t`) captures schedule velocity far
  more accurately than broad archetype aggregates. Adding archetype aggregates
  injects tree-splitting variance.

Key Takeaway for Schedule Revision:
- The apparent PR-AUC lift in Model B (+0.0121) is entirely isolated to Config E
  (`is_legacy_linked` + `cluster_distance_to_centroid_t`).
- Outcome statistics (Config C, Δ = -0.0003) and Cluster IDs (Config F, Δ = +0.0005)
  contribute zero incremental signal.
- The signal in Config E originates almost exclusively from the static binary flag
  `is_legacy_linked` (indicating chronic multi-decade legacy projects).
- However, Config E severely degrades probability calibration (Brier score worsens
  from 0.0176 to 0.0207; ECE worsens from 0.0202 to 0.0231) by inflating revision
  probabilities across legacy projects that do not experience revisions in the
  short 3-month forecast window.

--------------------------------------------------------------------------------
3. SYNTHESIS OF ABLATION FINDINGS
--------------------------------------------------------------------------------
1. Historical Outcome Rates (Config C): Produce ZERO or slightly negative gains
   across all three targets. Broad archetype averages do not improve short-term
   (3-month) forward risk prediction.
2. Deviations & Outlier Distances (Config D & E): Point-in-time deviations do not
   improve discrimination. `is_legacy_linked` provides a slight correlation with
   chronic revision history, but at the cost of probability calibration.
3. Cluster Membership (Config F): One-hot cluster IDs do not provide predictive
   advantage over the baseline, proving that archetype boundaries do not create
   orthogonal decision partitions for ML trees or linear classifiers.
