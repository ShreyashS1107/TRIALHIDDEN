1. EXECUTIVE SUMMARY & AUDIT PURPOSE
--------------------------------------------------------------------------------
Before evaluating project-archetype historical benchmarks in the controlled ML
experiment (Phase 2B), a mandatory mathematical and semantic audit was conducted
on all 12 candidate benchmark statistics constructed during Phase 2A.

Key Audit Objectives:
1. Establish the exact numerator, denominator, denominator type, unique project
   count, and observation count for every benchmark statistic.
2. Investigate suspicious or extreme statistical figures (e.g., Cluster 0 ~99%
   cost revision rate, Cluster 0 ~99% stagnation rate, Cluster 2 251-month median
   delay, sample sizes N > clustered project count).
3. Classify every benchmark into one of four formal semantic categories:
   - VALID
   - VALID BUT NEED CLEAR DENOMINATOR DOCUMENTATION
   - SEMANTICALLY INVALID
   - UNRELIABLE DUE TO SAMPLE / DEFINITION
4. Enforce strict inclusion/exclusion rules for Model B training to prevent
   corrupted, mislabeled, or circular features from entering the predictive pipeline.

2. DETAILED INVESTIGATION OF SPECIFIC ANOMALIES
--------------------------------------------------------------------------------

[INVESTIGATION 1] Cluster 0 ~99% Cost Revision Rate (0.9921)
------------------------------------------------------------
- Observation: In Cluster 0 ("High Administrative Cost-Revision Volatility", N=252),
  the historical cost revision rate was reported as 99.21%.
- Semantic Audit Finding:
  * Denominator Type: Unique historical clustered projects in Cohort A (N=252).
  * Numerator: Projects with >= 1 pre-PAIMANA administrative cost revision (N=250).
  * Rate: 250 / 252 = 99.2063% (smoothed: 98.44%).
  * Root Cause: Cluster 0 was explicitly clustered around extreme cost volatility
    and historical administrative revisions. The 99.2% rate is factually accurate
    and reflects the defining archetype property of these 252 mega-projects.
  * Audit Classification: VALID.

[INVESTIGATION 2] Cluster 0 ~99% Stagnation Rate (0.9960)
--------------------------------------------------------
- Observation: In Cluster 0, the historical stagnation rate was reported as 99.60%.
- Semantic Audit Finding:
  * Denominator Type: Unique historical clustered projects in Cohort A (N=252).
  * Numerator: Projects meeting the heuristic condition (N=251).
  * Root Cause: The Phase 2A script used a proxy rule `(n_snapshots >= 3)` as a
    proxy for longitudinal exposure. In Cohort A, 251 out of 252 projects had >= 3
    historical snapshots. This measured *longitudinal data availability*, NOT true
    physical/financial stagnation (e.g., zero physical progress over 6+ months).
  * Audit Classification: SEMANTICALLY INVALID (Mislabeled Construct).
  * Action: EXCLUDED from Model B.

[INVESTIGATION 3] Cluster 2 ~251-Month Median Delay (251.0 months)
------------------------------------------------------------------
- Observation: In Cluster 2 ("Severe Legacy Stagnation & Chronic Slippage", N=69),
  the median historical delay was reported as 251.0 months (~20.9 years).
- Semantic Audit Finding:
  * Denominator Type: Unique historical clustered projects in Cohort A (N=69).
  * Numerator: Median delay across all 69 legacy projects.
  * Root Cause: Cluster 2 consists of chronic legacy railway lines, national highway
    bypass corridors, and irrigation dams sanctioned between 1985 and 2005. These
    projects suffered decades of land acquisition bottlenecks and forest clearances.
    The 251-month median delay is mathematically accurate and clinically describes
    the severe historical delay archetype.
  * Audit Classification: VALID.

[INVESTIGATION 4] Cluster 1 Evidence N > Clustered Project Count (N=3,266 vs 946)
---------------------------------------------------------------------------------
- Observation: Cluster 1 has 946 unique clustered projects in Cohort A, but total
  evidence observations in Phase 2A tables showed N=3,266.
- Semantic Audit Finding:
  * Denominator Type: Combined historical observation records (completed project
    outcomes from OCMS pre-PAIMANA repository + longitudinal project profiles).
  * Breakdown:
    - 946 unique projects in active PAIMANA monitoring.
    - 2,320 completed historical project records linked by sector/agency archetype
      prior to PAIMANA epoch.
  * Audit Classification: VALID BUT NEED CLEAR DENOMINATOR DOCUMENTATION.

[INVESTIGATION 5] Global Benchmark Sample Size N = 3,831
-------------------------------------------------------
- Observation: Global prior pool reports N = 3,831.
- Semantic Audit Finding:
  * Denominator Type: Total unique pre-PAIMANA historical projects in OCMS database
    (1,442 linked Cohort A + 2,389 historical completed/archived projects).
  * Audit Classification: VALID BUT NEED CLEAR DENOMINATOR DOCUMENTATION.

4. MODEL B FEATURE INCLUSION / EXCLUSION DECISIONS
--------------------------------------------------------------------------------

[INCLUDED IN MODEL B] (6 Valid Features):
1. cluster_hist_delay_rate_smoothed_t:
   - Reason: Valid historical delay proportion across archetype completed projects;
     strictly point-in-time safe (pre-PAIMANA evidence).
2. cluster_hist_median_delay_months_t:
   - Reason: Valid historical central tendency of delay duration for archetype.
3. cluster_hist_cost_revision_rate_t:
   - Reason: Valid measure of historical administrative revision volatility.
4. cluster_distance_to_centroid_t:
   - Reason: Point-in-time distance measuring how typical or outlier a project is
     relative to its assigned archetype center.
5. cluster_slippage_deviation_t:
   - Reason: Measures whether the project's current slippage exceeds or lags its
     archetype median baseline.
6. is_legacy_linked:
   - Reason: High-fidelity indicator of longitudinal legacy project status.

[EXCLUDED FROM MODEL B] (6 Excluded Features):
1. cluster_hist_stagnation_rate_t:
   - Reason: SEMANTICALLY INVALID. Mislabeled longitudinal snapshot frequency.
2. cluster_stagnation_deviation_t:
   - Reason: SEMANTICALLY INVALID. Directly derived from invalid stagnation rate.
3. cluster_hist_schedule_revision_rate_t:
   - Reason: UNRELIABLE. Extreme sparsity in historical OCMS pre-PAIMANA records
     due to differences in revision logging standards prior to 2023.
4. cluster_hist_mean_delay_months_t:
   - Reason: REDUNDANT with median delay (median is more robust to extreme outliers).
5. cluster_hist_cost_escalation_rate_t:
   - Reason: REDUNDANT and collinear with `cost_escalation_pct_t` in PAIMANA.
6. cluster_cost_esc_deviation_t:
   - Reason: REDUNDANT; perfect linear combination with PAIMANA `cost_escalation_pct_t`.

The semantic audit successfully isolated 6 mathematically and semantically sound
